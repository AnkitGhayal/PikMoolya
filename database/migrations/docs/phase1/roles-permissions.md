# Roles and Permissions

## Farmer

Can:
- register/login and manage profile
- manage farms
- create/edit/publish produce listings
- upload produce images
- request/view AI quality assessment
- view fair-price certificate and explanation
- calculate price floor
- compare markets
- run sell-now-vs-wait simulation
- view buyer matches
- start selling rounds/auctions
- receive, accept, reject and negotiate offers
- create/opt into collective sales
- create/view orders
- track shipments
- view delivery quality
- view payments and transaction history
- view produce passport
- rate buyers
- use AI assistant and voice input
- change language

## Buyer

Can:
- register/login and manage profile
- create crop/quality/quantity requirements
- browse and filter listings
- view AI-assisted quality assessment
- view fair-price information
- make bids/offers
- negotiate
- participate in auctions
- create/view orders
- coordinate delivery
- perform delivery quality verification
- raise evidence-based disputes
- rate farmers

## Logistics Partner

Can:
- view assigned delivery jobs
- accept/reject jobs
- submit transport cost
- update pickup/shipment/delivery status
- attach delivery evidence

## Admin

Can:
- manage users
- verify accounts
- manage market data
- monitor listings, predictions and quality
- monitor auctions/orders/payments
- review disputes and risk flags
- configure platform settings
- view analytics
- inspect audit logs

Security rule: permissions are enforced server-side; UI hiding is not authorization.
